# Iris-Dataset

## Description
The Iriis Dataset is a classic dataset. It contains measuremenst of four features ( septal length, septal width, petal length, and petal width) for 150 iris flowers from three species: Setsoa, Versicolor, and Versicolor, and Virginca. This dataset is commonly used forntrsting and practcing algorthims.
